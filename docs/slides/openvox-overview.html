Install

One command. ~45 seconds.

# macOS or Linux
curl -fsSL https://github.com/amznsri/openvox/releases/latest/download/install.sh | bash
openvox start                       # daemon + dashboard auto-opens at localhost:8000

Detects Python 3.11+, picks pipx (or a venv fallback), drops openvox on PATH. First-run wizard at http://localhost:8000/dashboard/setup handles API keys end-to-end.

Alternative paths: pipx install openvox-core · brew install amznsri/openvox/openvox · winget install OpenVox.OpenVox

Extending OpenVox

Three plug points. All Python or TypeScript.

Skill

Drop a Python file

Subclass BaseSkill with id, description, JSON-schema parameters, and an async run(). Hot-reloaded from ~/.openvox/skills/.

Provider

Custom STT / LLM / TTS

Subclass the matching Provider base. Register via the openvox.providers entry point. The dashboard picks it up automatically.

Template

Ship a starter

Add a dict to routes/templates.py. New users see it in the Templates gallery, ready to clone with prompt + voice + skills pre-configured.

Plus Model Context Protocol: connect any MCP server — Slack, GitHub, Notion, HubSpot, Salesforce, Stripe — as agent tools. Curated catalogue ships in the box.

Local-first by default

Your audio, your transcripts, your servers.

OpenVox runs on a laptop with SQLite and the local filesystem. Audio and transcripts only leave your machine when they hit a provider you configured.

Want to go fully on-device? Local Whisper + Ollama + Piper covers STT + LLM + TTS without a network hop. The same agents, with no third party seeing the audio.

Production scale up: Postgres, S3-compatible storage, OpenTelemetry instrumentation, structured logs. Same single binary.
